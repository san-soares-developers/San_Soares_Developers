[ Produtos & Soluções SaaS em Portfólio ]

1. Sistema de Gestão Distribuída Multi-Tenant (SaaS Tabacaria Reis)

  • Arquitetura Backend: Desenvolvido com robustez em Java 21 e Spring Boot 3.4.
  • Controle de Acesso Polimórfico: Autenticação flexível via Pattern Strategy e Spring Security, centralizando múltiplas personas no mesmo endpoint público.
  • Performance em Escala: Integração com Redis para gerenciamento de cache de sessão distribuída na memória RAM, mitigando a latência de rede.
  • Compliance de Dados: Criptografia de dados sensíveis na persistência (PostgreSQL) via AttributeConverter do JPA, isolando o histórico de consentimento com IP e User-Agent.

2. Plataforma Corporativa de Recrutamento & Automação (SaaS Vagas Construção)

  • Arquitetura Mobile-First: Interface limpa e responsiva voltada para usabilidade imediata em smartphones.
  • Integração Financeira: Automatização ponta a ponta de esteira de cobrança recorrente via PIX e Boleto.
  • Orquestração de Mensageria: Fluxos de notificações assíncronas disparados nativamente para o WhatsApp através da integração entre n8n e Redis.
  • Proteção de Licença: Modelo baseado em Tenant Cut-Off (disjuntor automático de inadimplência), retornando Status 403 Forbidden para proteção de ativos.
